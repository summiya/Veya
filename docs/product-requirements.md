# Product Requirements Document

## Product

Veya

## Problem

Creators need to understand how audiences respond to their content, but reading large numbers of comments can expose them repeatedly to hostility, abuse, spam, and emotionally draining feedback.

Traditional social analytics focuses heavily on engagement metrics such as likes, views, reach, and follower counts. Veya focuses on audience sentiment and comment wellbeing.

## Product goal

Give creators a useful interpretation of audience response while minimizing unnecessary exposure to harmful comments.

## Product principles

1. Feedback should become information, not emotional overload.
2. Constructive criticism should not be treated as abuse.
3. Negative sentiment should still be represented in analytics.
4. Toxic content should not dominate the user experience.
5. Users remain in control of whether harmful comments are revealed.

## MVP user journey

1. User opens Veya.
2. User connects an Instagram professional account.
3. Veya retrieves recent media.
4. Veya retrieves comments.
5. Veya classifies sentiment.
6. Veya calculates percentages.
7. User sees profile-level sentiment.
8. User opens a specific post.
9. User sees post-level sentiment and comment totals.

## MVP screens

### Connect Instagram

Purpose:
- Start Instagram authorization.
- Show connection state.

### Dashboard

Show:
- Profile positivity percentage.
- Positive percentage.
- Neutral percentage.
- Negative percentage.
- Total comments analyzed.
- Recent posts.

### Posts

Show:
- Post thumbnail.
- Post date.
- Comment count.
- Positive percentage.
- Neutral percentage.
- Negative percentage.

### Post Details

Show:
- Post metadata.
- Sentiment breakdown.
- Total comments analyzed.
- Sample positive comments where appropriate.
- Future space for constructive feedback and Comment Shield.

## Success criteria

The MVP is successful when:

- A creator can connect an Instagram account.
- Veya can retrieve comments from owned media.
- Sentiment percentages are generated reliably.
- Results are visible in the frontend.
- The user can compare sentiment across posts.
